A TTCharacterAdministration is a central administration for characters.

Instance Variables
	monsters:		<OrderedCollection>
	npcs:		<OrderedCollection>
	playerCount:		<Number>
	playerSelectionMenu:		<TTPlayerSelectionMenu>
	players:		<OrderedCollection>

monsters
	- stores all available TTMonsters

npcs
	- stores all npcs TTCharacter

playerCount
	- stores the number of players

playerSelectionMenu
	- stores the TTPlayerSelectionMenu of the characters in the TTCharacterAdministration

players
	- stores all the players TTCharacter
