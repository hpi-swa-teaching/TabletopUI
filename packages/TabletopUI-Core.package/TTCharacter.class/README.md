A TTCharacter is a participant in the game which gets either controlled by a player or the gamemaster. 

Instance Variables
	name:		<String>
	role:		<Symbol>
	sheet:		<Object>
	token:		<TTToken>

name
	- stores the name of the character

role
	- stores the role of the character

sheet
	- stores the sheet of the character

token
	- stores the token of the character
