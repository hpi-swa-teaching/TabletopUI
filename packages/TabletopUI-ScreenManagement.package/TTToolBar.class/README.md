A TTToolBar is a sidebar where you have shortcuts to important functionalities

Instance Variables
	characterAdministration:		<TTCharacterAdministration>
	characterSheetActive:		<Boolean>
	diceTool:		<TTDiceToolDisplay>
	inputField:		<TTInputField>
	map:		<TTMap>

characterAdministration
	- stores information about the participating characters

characterSheetActive
	- stores whether the currently selected player has a character sheet

diceTool
	- stores the dice tool

inputField
	- stores the input field of the console to print the dice rolls of the dice tool

map
	- stores the map to measure distances with the ruler tool
